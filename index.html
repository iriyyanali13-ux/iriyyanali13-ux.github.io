Used Parts Buyer's Guide

Don't get scammed in the used market. Run these tests before buying:

  • 1. GPU Stress Run FurMark for 15 mins. Max temp should be < 85°C.
  • 2. Drive Health Use CrystalDiskInfo. Must be 100% / Good.
  • 3. Power Stability Restart the PC 3 times to test the PSU.
